# Mystaria — Public player edition

These are the current Living Codex teaching pages. The author directs the website to teach HP/d20 with Training Points as the current game, without a playtest label. They are concise player-facing explanations derived from the owning subject references, rather than a separate authority for new lore or numerical choices.

Update the affected teaching pages alongside approved subject changes. Teach the resulting rule directly; keep supersession history, simulation jobs, discarded candidates and maintenance discussion in the subject manuscripts and changelog. Preserve the latest approved qualifications and leave genuinely unresolved details for table adjudication. Do not fill missing costs, racial Skill arrays, item conversions or formulas.

The website explicitly selects these files in its reading manifest, ingests the latest main, expands reviewed `{{table:...}}` source tables, renders Markdown and `::: detail` optional sections, and regenerates navigation/search/downloads. Website implementation remains in [mystaria-living-codex](https://github.com/MyStalker/mystaria-living-codex). A new paragraph or section in an included guide needs no website code or manual deployment. A new guide needs an explicit reading-manifest entry and privacy review.

The economy comparison and mana/food/trade guides also draw from [mystaria-economy](https://github.com/MyStalker/mystaria-economy). The latest approved owning subject reference remains controlling when a teaching summary needs reconciliation.
