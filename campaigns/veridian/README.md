## Recordkeeping conventions

- Record events that have happened as **CONFIRMED**.
- Mark intended future events and prepared scenes as **PLANNED**.
- Mark ideas not yet accepted at the table as **PROPOSAL**.
- Mark unresolved facts as **UNRESOLVED** rather than filling gaps with guesses.
- Distinguish official Mystaria rules/lore from campaign-specific additions and homebrew.
- Update the session log after play, then revise the current adventure, character records, and open threads when the fiction changes.
